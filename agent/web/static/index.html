    The agent loop

    1. 1 Check budget
    2. 2 Call model
    3. 3 Read stop_reason
    4. 4 Run tools
    5. 5 Send results back
    6. ✓ Answer

    Every trip around steps 1–5 is one step. The loop repeats until the model answers (end_turn) or a budget runs out. That's the whole agent: the model decides, the harness acts.
